# Versioning

Semantic Versioning (`MAJOR.MINOR.PATCH`) tracked in `VERSION`.

Every change commit MUST:
1. Bump `VERSION` — PATCH for fixes/tweaks, MINOR for new features, MAJOR for breaking changes.
2. Add a dated entry to `CHANGELOG.md` under the new version.
3. Use a commit message of the form: `vX.Y.Z: <concise summary>`.

Branching: `main` only for now.
